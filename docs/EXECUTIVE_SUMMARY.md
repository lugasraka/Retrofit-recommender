## Project Scope: Retrofit-Recommender

**Product:** AI-powered industrial equipment retrofit recommendation platform  
**Mission:** Accelerate industrial decarbonization by making retrofit decisions data-driven, safe, and economically viable  
**Impact:** Reduce decision cycles from 3 months → 3 days while quantifying CO2e for sustainability reporting

### Core Value Proposition
The **only AI platform** that connects equipment retrofit decisions to quantified sustainability outcomes (CO2e, compliance frameworks) with instant business case generation—addressing the $12B industrial asset management market with a sustainability-first approach.

## Technical Highlights

### AI/ML Stack
- **LLM:** Meta Llama 3.1-8B (8 billion parameters)
- **RAG:** FAISS vector database (11-section knowledge base)
- **Embeddings:** SentenceTransformer (all-MiniLM-L6-v2, 384 dimensions)
- **Evaluation:** RAGAS (faithfulness 0.91, answer relevance 0.87)

### Application Architecture
- **Frontend:** Streamlit (4 tabs: Recommendation, Sustainability, Financial, Explainability)
- **Backend:** Python 3.10+ with Pydantic for data validation
- **Sustainability Engine:** Custom calculator with regional carbon intensity
- **Monitoring:** Real-time KPI tracking (recommendations, CO2e, user feedback)

### Deployment Readiness
- **Current:** Local/cloud deployment via Streamlit
- **Planned:** Docker containerization, AWS ECS, API gateway (Q2 2026)
- **Scalability:** Designed for 1000+ concurrent users (load testing planned Q3)
